(খ) 20 J
(গ) 100 J
(ঘ) 200 J

2. If θ = 30°, find sinθ + cosθ where Δ = √3/2 and π ≈ 3.14:
A. 1 + √3/2
B. (1 + √3)/2
C. √3
D. 1/2
Answer: B
  • সূত্র প্রশ্নের লাইনেই লিখুন: Eₖ = ½mv², sinθ, √3/2।
  • একক অপশনে: 10 J, 5 Ω, 20 m/s।
  • ভগ্নাংশ inline লিখুন: 1/2, (1 + √3)/2।

ⓘ Stem / উদ্দীপক / বহু-লাইন প্রশ্নের নিয়ম

Equation বা বাড়তি লাইন যেভাবে লিখবেন

১। উদ্দীপকটি পড়ো এবং উত্তর দাওঃ
- পানির সংকেত H₂O
- লবণের সংকেত NaCl
উপরের কোনটি সঠিক?
(ক) i ও ii
(খ) শুধু i
(গ) শুধু ii
(ঘ) কোনটিই নয়
সঠিক উত্তর: ক
  • বাড়তি লাইন সাধারণ লাইন বা - দিয়ে লিখুন — প্রশ্নের সাথেই থাকবে (verified)।
  • Stem-এর ভেতরে i. ii. 1. 2. দিয়ে লাইন শুরু করবেন না — এগুলো আলাদা প্রশ্ন ধরা হয়।
  • সমীকরণ সবসময় এক লাইনে রাখুন।
✗ ভুল ফরম্যাট (এড়িয়ে চলুন) 
সঠিক উত্তর: (ঘ) হাঙ্গর     ← ভুল (উত্তর detect হয় না, বড় সেটে প্রশ্নও ভাঙে)
সঠিক উত্তর: ঘ              ← সঠিক
  • উত্তরের লাইনে শুধু এক অক্ষরের লেবেল — অপশনের টেক্সট আবার লিখবেন না।
  • প্রশ্নের মাঝখানে Answer Key: / উত্তরমালা হেডিং দেবেন না।
  • অপশনের আগে stem-এ A. / ক) দিয়ে লাইন শুরু করবেন না — অপশন ধরা হয়।

📝 Exam Paste Format Guide — English Version

Admin Panel → Add Exam → Paste Questions → Detect Questions — works for Biology, Physics, Chemistry, English. Paste 10 / 20 / 50 / 100+ questions at once. Write reactions, subscripts, superscripts, equations and symbols in Unicode so detection works (verified).
Step 1: Paste questions in the format below (answer = label only).
Step 2: Click Detect Questions → all items appear in preview.
Step 3: Review and click Save Questions.
✓ Biology format (verified)

Write answer as label only (A / B / C / D)

1. Which type of caudal fin is heterocercal? [Dhaka Board 19]
A. Rui
B. Lungfish
C. Taki
D. Shark
Answer: D

2. Which animal has a completely four-chambered heart?
A. Lizard
B. Crocodile
C. Turtle
D. Snake
Answer: B
  • Question number: 1. 2) Q1.
  • Options: A. B. C. D. / (A) (B) (C) (D) / A) B) C) D)
  • Answer: Answer: D / Ans: B / Correct Answer: (B)
  • Keep board tag on the question line: [Dhaka Board 19]. Keep a blank line between questions.
✓ Physics format (verified)

Formula, unit, symbol — in one line, in Unicode

1. An object has velocity v = 10 m/s and mass m = 2 kg. What is the kinetic energy (Eₖ = ½mv²)? [Dhaka Board 19]
A. 10 J
B. 20 J
C. 100 J
D. 200 J
Answer: C

2. If θ = 30°, find sinθ + cosθ where Δ = √3/2 and π ≈ 3.14:
A. 1 + √3/2
B. (1 + √3)/2
C. √3
D. 1/2
Answer: B
  • Write the formula on the question line: Eₖ = ½mv², sinθ, √3/2.
  • Units in options: 10 J, 5 Ω, 20 m/s.
  • Write fractions inline: 1/2, (1 + √3)/2.
✓ Chemistry format (verified)

Reaction in one line — subscript/superscript in Unicode

1. In the reaction 2H₂ + O₂ → 2H₂O, how many moles of oxygen are needed? [Dhaka Board 19]
A. 1
B. 2
C. 3
D. 4
Answer: A

2. How many electrons does Ca²⁺ have? (Ca = 20)
A. 18
B. 20
C. 22
D. 16
Answer: A

3. For A + B ⇌ C + D at equilibrium with K꜀ = 4, what is ΔG°?
A. -3.44 kJ/mol
B. +3.44 kJ/mol
C. -34.4 kJ/mol
D. 0 kJ/mol
Answer: A
  • Reaction: 2H₂ + O₂ → 2H₂O, reversible: A + B ⇌ C + D.
  • Compounds: H₂SO₄, NaCl. Ions: Ca²⁺, SO₄²⁻.
  • Do not type the ₂ in H₂ as a normal 2 — copy subscript from the palette above.

ⓘ Stem / multi-line question rule

How to write extra lines and equations

1. Read the stem and answer:
- Formula of water is H₂O
- Formula of salt is NaCl
Which of the above is correct?
A. i and ii
B. Only i
C. Only ii
D. None
Answer: A
  • Write extra lines as plain lines or with - — they stay with the question (verified).
  • Do not start a line inside the stem with i. ii. 1. 2. — those are detected as new questions.
  • Always keep equations on one line.
✗ Wrong format (avoid) 
Answer: (D) Shark     ← wrong (answer not detected, breaks large sets)
Answer: D              ← correct
  • Answer line must contain only a single-letter label — do not repeat the option text.
  • Do not add an Answer Key: heading in the middle of questions.
  • Do not start a stem line with A. before the options — it will be treated as an option.
